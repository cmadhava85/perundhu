# Perundhu — Social Media Video Script

**Format:** Vertical (9:16) | **Duration:** 30 seconds  
**Style:** Text slides with background visuals  
**Target Platforms:** Instagram Reels, YouTube Shorts, Facebook Reels  

---

## Scene 1 — Hook (0–4 seconds)

| Property | Content |
|---|---|
| **Background visual** | Busy bus stop, people waiting, slight blur |
| **Effect** | Fade in with slow zoom |

**Text overlay (large, bold, centre):**
```
எனக்கு சரியான பேருந்து தகவல் கிடைக்கவில்லை…
(I couldn't find the right bus information…)
```

**Voiceover Tamil:**
> "எனக்கு சரியான பேருந்து தகவல் கிடைக்கவில்லை."

**Voiceover English:**
> "I couldn't find the right bus information."

---

## Scene 2 — Relate to Audience (5–10 seconds)

| Property | Content |
|---|---|
| **Background visual** | Three quick cuts — student with bag, office worker at bus stop, daily commuter checking phone |
| **Effect** | Each line slides in from the left, 1.5 seconds apart |

**Text overlay (each line appears one at a time):**
```
மாணவரா?           (Student?)
தினசரி பயணியா?    (Daily commuter?)
வேலைக்கு போகிறவரா? (Travelling for work?)
```

**Voiceover Tamil:**
> "நீங்கள் மாணவரா, தினசரி பயணியா, அல்லது வேலைக்கு போகிறவரா?"

**Voiceover English:**
> "Are you a student, a daily commuter, or someone travelling for work?"

---

## Scene 3 — Introduce the App (11–18 seconds)

| Property | Content |
|---|---|
| **Background visual** | Clean white or light background, or app screenshot |
| **Effect** | App logo fades in first, then each point slides in |

**Text overlay (numbered list, appears line by line):**
```
Perundhu

1. பேருந்து routes தேடுங்கள்   (Search bus routes)
2. முடிவுகளை உடனே பாருங்கள்  (View results instantly)
3. இல்லாத தகவல் சேருங்கள்    (Add missing details)
```

**Voiceover Tamil:**
> "Perundhu-வில் பேருந்து routes தேடலாம், முடிவுகளை உடனே பார்க்கலாம், இல்லாத தகவல்களை நீங்களே சேர்க்கலாம்."

**Voiceover English:**
> "With Perundhu, search bus routes, view results instantly, and add missing details through Manual Contribution."

---

## Scene 4 — Emotional Appeal (19–25 seconds)

| Property | Content |
|---|---|
| **Background visual** | One person helping another at a bus stop, or a simple animated bus icon |
| **Effect** | Slow fade in, text pulses gently |

**Text overlay (2 lines, bold):**
```
நீங்கள் அறிந்த ஒரு தகவல்
ஆயிரம் பேருக்கு உதவலாம்

(What you know can help thousands)
```

**Voiceover Tamil:**
> "நீங்கள் தினமும் பயன்படுத்தும் route தகவல், இன்னும் ஆயிரக்கணக்கான பயணிகளுக்கு உதவலாம். உங்கள் ஒரு பங்களிப்பு மிகவும் முக்கியம்."

**Voiceover English:**
> "The route information you use every day can help thousands of other travellers. Your one contribution matters."

## Canva Setup Guide

| Setting | Value |
|---|---|
| Size | 1080 x 1920 (Reels / TikTok / Shorts) |
| Duration | 30 seconds total |
| Font (English) | Poppins Bold or Montserrat Bold |
| Font (Tamil) | Noto Sans Tamil Bold |
| Background music | Soft motivational — search "positive background music" in Canva free library |
| Caption style | Auto-captions, white text, dark background strip |

**Steps in Canva:**
1. Go to canva.com → New Design → Instagram Reel
2. Create 5 slides using the scenes above
3. Add free bus/travel stock video from Canva's media library
4. Paste the text overlays as written in each scene
5. Add a soft background music track from Canva's free library
6. Export as MP4 → Post directly to Instagram, Facebook, or YouTube Shorts

---

## CapCut Setup Guide (Mobile — Fastest Option)

| Setting | Value |
|---|---|
| Ratio | 9:16 vertical |
| Duration | 30 seconds |
| Caption | Enable Auto Captions |
| Music | Use CapCut's built-in royalty-free music — search "motivational soft" |

**Steps in CapCut:**
1. Open CapCut → New Project → Add a blank video or a bus photo
2. Add Text for each scene using the overlay text above
3. Use Auto Captions to display voiceover text on screen
4. Add Sticker or transition between each scene
5. Export and post directly to Instagram / YouTube Shorts / Facebook
