# Perundhu — Social Media Video Script

**Format:** Vertical (9:16) | **Duration:** 60–90 seconds  
**Style:** Screen recording with voiceover and text overlays  
**Target Platforms:** Instagram Reels, YouTube Shorts, Facebook Reels  

---

## Scene 1 — Introduction (0–15 seconds)

| Property | Content |
|---|---|
| **Background visual** | Busy bus stop in a small town or village, people waiting, slight blur |
| **Effect** | Fade in with slow zoom, text appears word by word |

**Text overlay (large, bold, centre):**
```
வணக்கம் நண்பர்களே!

தமிழ்நாட்டில் பேருந்து நேரம் தெரியாமல்
திண்டாடுகிறீர்களா?
```

**Voiceover Tamil:**
> "வணக்கம் நண்பர்களே! தமிழ்நாட்டில், குறிப்பாக சிறு நகரங்களிலும் கிராமங்களிலும், சரியான பேருந்து நேரத்தை தெரிந்துகொள்வது மிகவும் கடினமாக இருக்கிறது. பலரும் பேருந்து நேரம் தெரியாமல் திண்டாடுகிறார்கள். இந்தப் பிரச்சனையை தீர்க்கவே 'பேருந்து' website உருவாக்கப்பட்டது. இந்த website மூலம் எந்த இடத்திலிருந்தும் எந்த இடத்திற்கும் பேருந்து நேரத்தை எளிதாக தெரிந்துகொள்ளலாம். தற்போது எங்கள் குழுவினர் பல இடங்களுக்கான பேருந்து நேர தகவல்களை சேகரித்து வருகிறோம். ஆனால், நீங்கள் அறிந்திருக்கும் பேருந்து நேரங்களை இங்கே பகிர்ந்துகொண்டால், அது இன்னும் பலருக்கு மிகவும் உதவியாக இருக்கும்."

**Voiceover English (subtitle reference):**
> "Hello friends! Finding bus timings in Tamil Nadu — especially in small towns and villages — is very difficult. Many people struggle without this information. The Perundhu website was created to solve this problem. Using this website, anyone can easily find bus timings between any two locations. Our team has already collected bus schedules for many places, but we need your help — if you share the bus timings you know, it will be very useful to many others."

## Scene 2 — Screen Walkthrough: Search (16–35 seconds)

| Property | Content |
|---|---|
| **Background visual** | Live screen recording of the Perundhu website in a browser |
| **Effect** | Smooth scroll and tap animations; highlight boxes on each action |

**On-screen actions (record in sequence):**
1. Open browser → type the Perundhu URL
2. Type origin location (e.g., Madurai)
3. Type destination location (e.g., Dindigul)
4. Tap the **Search** button
5. Search results appear → slowly scroll down one page
6. Bus list is visible → tap on one bus entry to **expand stops**
7. Stops list is revealed and visible on screen

**Text overlay (appears with each action):**
```
URL உள்ளிடுங்கள்           → Type the URL
புறப்படும் இடம் தேர்வு செய்யுங்கள் → Select origin
சேரும் இடம் தேர்வு செய்யுங்கள்   → Select destination
தேடுங்கள்!                → Search!
பேருந்து பட்டியல்          → Bus list
நிறுத்தங்களை பாருங்கள்      → View stops
```

**Voiceover Tamil:**
> "முதலில் browser-ல் website-ஐ திறந்து, புறப்படும் இடம் மற்றும் சேரும் இடத்தை உள்ளிட்டு தேடுங்கள். முடிவுகளில் உங்களுக்கு தேவையான பேருந்துகளின் பட்டியல் தெரியும். கீழே scroll செய்து அனைத்து பேருந்துகளையும் பார்க்கலாம். ஒரு பேருந்தை கிளிக் செய்தால், அதன் நிறுத்தங்களையும் விரிவாக பார்க்கலாம்."

**Voiceover English (subtitle reference):**
> "First, open the website in your browser, enter your origin and destination, then tap Search. The results will show a list of matching buses. Scroll down to see all available buses. Tap on any bus to expand and view its full stop list."

## Scene 3 — Screen Walkthrough: Contribution (36–55 seconds)

| Property | Content |
|---|---|
| **Background visual** | Continuing screen recording — navigate to the Contribution page |
| **Effect** | Smooth navigation, highlight boxes on each input field |

**On-screen actions (record in sequence):**
1. Navigate to the **Contribution** page (tap the Contribute button or menu)
2. Enter or select a **Bus Number / Route**
3. Select **Origin** location
4. Select **Destination** location
5. Select **Departure Time**
6. Tap **Submit**
7. Success message appears on screen (highlight and pause for 2 seconds)

**Text overlay (appears with each action):**
```
பங்களிப்பு பக்கம்        → Contribution page
பேருந்து எண் / Route     → Bus number / Route
புறப்படும் இடம்          → Origin
சேரும் இடம்             → Destination
புறப்படும் நேரம்         → Departure time
Submit செய்யுங்கள்       → Submit
✅ வெற்றிகரமாக சேர்க்கப்பட்டது! → Contribution successful!
```

**Voiceover Tamil:**
> "இப்போது Contribution பக்கத்திற்கு செல்லுங்கள். பேருந்து எண் அல்லது route-ஐ தேர்வு செய்யுங்கள். புறப்படும் இடம், சேரும் இடம் மற்றும் நேரத்தை உள்ளிட்டு Submit செய்யுங்கள். உங்கள் பங்களிப்பு வெற்றிகரமாக சேர்க்கப்பட்டது என்ற செய்தி தெரியும். இவ்வளவு எளிது!"

**Voiceover English (subtitle reference):**
> "Now go to the Contribution page. Select the bus number or route. Enter the origin, destination, and departure time, then tap Submit. You will see a success message confirming your contribution. It's that simple!"

## Canva Setup Guide

| Setting | Value |
|---|---|
| Size | 1080 x 1920 (Reels / TikTok / Shorts) |
| Duration | 30 seconds total |
| Font (English) | Poppins Bold or Montserrat Bold |
| Font (Tamil) | Noto Sans Tamil Bold |
| Background music | Soft motivational — search "positive background music" in Canva free library |
| Caption style | Auto-captions, white text, dark background strip |

**Steps in Canva:**
1. Go to canva.com → New Design → Instagram Reel
2. Create 5 slides using the scenes above
3. Add free bus/travel stock video from Canva's media library
4. Paste the text overlays as written in each scene
5. Add a soft background music track from Canva's free library
6. Export as MP4 → Post directly to Instagram, Facebook, or YouTube Shorts
