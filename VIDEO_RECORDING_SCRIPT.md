## 🎨 Visual Guidelines

### Color Scheme
- **Primary:** Green (#10B981) - for highlights
- **Secondary:** Blue (#3B82F6) - for actions
- **Accent:** Orange (#F59E0B) - for important elements
- **Background:** White/Light gray

### Typography
- **Titles:** Bold, minimum 44pt
- **Body Text:** Regular, minimum 36pt
- **Keep text on screen for at least 2 seconds**

### Transitions
- **Between clips:** Simple fade (0.3s)
- **Text entrance:** Slide up + fade in
- **Text exit:** Fade out
- **Keep it smooth and professional**

## 📱 Recording Setup Checklist

### Before Recording:

- [ ] Phone fully charged (80%+)
- [ ] Clear all notifications
- [ ] Enable Do Not Disturb
- [ ] Clean phone screen
- [ ] Close unnecessary apps
- [ ] Good lighting (natural or ring light)
- [ ] Stable surface or tripod
- [ ] Test app functionality
- [ ] Prepare demo data (if needed)

### Recording Settings:

- [ ] Screen recording enabled
- [ ] High quality (1080p minimum)
- [ ] Orientation: Portrait (vertical)
- [ ] Microphone: ON (for voiceover)
- [ ] No background music during recording

### During Recording:

- [ ] Slow, deliberate movements
- [ ] Hold on important screens (2-3s)
- [ ] No sudden scrolling
- [ ] Clear taps/touches
- [ ] Practice run first

- **Volume:** Background only, don't overpower voiceover

## 🛠️ Recommended Editing Apps

### Mobile Apps (iOS & Android):
1. **CapCut** (FREE) - Best for beginners
   - Easy text overlays
   - Built-in music library
   - Auto-captions
   - Templates available

2. **InShot** (FREE with watermark)
   - Simple interface

   - Export without watermark ($3)

   - Professional quality
   - Cross-platform
   - Cloud sync

1. **DaVinci Resolve** (FREE)
   - Professional grade
   - No watermarks
   - Steep learning curve

## 💡 Pro Tips

1. **Show Real Use Cases:**
   - Use actual Tamil Nadu cities
   - Show real routes people use
   - Demonstrate during typical commute times

2. **Keep It Authentic:**
   - Don't use fake data
   - Show actual app performance
   - Be honest about features

3. **Engage With Viewers:**
   - Reply to comments quickly
   - Ask questions in captions
   - Create polls in stories
   - Share user feedback

4. **Test First:**
   - Record multiple takes
   - Show to friends for feedback
   - Check on different phone sizes
   - Verify all features work

5. **Follow Up:**
   - Create stories daily
   - Share user testimonials
   - Post updates and stats
   - Tease upcoming features
