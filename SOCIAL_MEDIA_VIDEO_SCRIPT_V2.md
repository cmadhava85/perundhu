## Production Guide

### Step 1: Record App Screens

Use one of these methods:

#### Option A: iOS Screen Recording (Easiest)
1. Open Perundhu app on iPhone
2. Enable screen recording: Settings → Control Center → Add Screen Recording
3. Start recording from Control Center
4. Perform the walkthrough actions listed above
5. Stop recording - video saved to Photos

#### Option B: Android Screen Recording
1. Open Perundhu app on Android
2. Swipe down notification panel
3. Tap "Screen record" (or use AZ Screen Recorder app)
4. Perform the walkthrough actions
5. Stop recording - video saved to Gallery

#### Option C: Simulator/Emulator Recording (Desktop)
```bash
# iOS Simulator (macOS)
xcrun simctl io booted recordVideo --codec=h264 app_recording.mov
# Then perform actions in simulator
# Press Ctrl+C to stop

# Android Emulator
adb shell screenrecord /sdcard/app_recording.mp4
# Then perform actions in emulator
# Press Ctrl+C to stop
# Pull video: adb pull /sdcard/app_recording.mp4
```

### Step 2: Process Screen Recording

1. **Trim** the recording to show only relevant sections
2. **Split** into 6 scenes matching the script
3. **Export** each scene as separate video file

Save to: `scripts/video-generation/assets/screens/`
- `scene1_launch.mp4` (5s)
- `scene2_search.mp4` (10s)
- `scene3_results.mp4` (13s)
- `scene4_stops.mp4` (12s)
- `scene5_contribute.mp4` (12s)
- `scene6_cta.mp4` (8s)

### Step 3: Generate Enhanced Voice-Over

```bash
cd scripts/video-generation
source venv/bin/activate
python generate_voiceover_v2.py
```

### Step 4: Combine Everything

```bash
python create_video_v2.py
```

This will:
- Use real app screen recordings
- Add Tamil voice-over
- Add text overlays
- Create final 60-second video

Before recording, ensure:

- ✅ Phone in Do Not Disturb mode (no notifications)

- ✅ Prepare search terms (Chennai → Madurai)
- ✅ Practice the flow once
- ✅ Good lighting for screen visibility
- ✅ Clean background (if phone is visible)
- ✅ Stable hand or use phone stand
