# 🎬 Quick Start: Record Videos Now!

## 3 Simple Steps:

### 1. Install FFmpeg (one-time setup)
```bash
brew install ffmpeg
```

### 2. Record Videos (automatically)
```bash
cd frontend
../record-demo-videos.sh
```
*This will take 2-3 minutes to record all 3 videos*

### 3. Convert to MP4 (for Instagram/Facebook)
```bash
cd ..
./convert-videos-to-mp4.sh
```

## 📁 Your Videos:
- **Location:** `demo-videos/mp4/`
- **Files:**
  - `01-search-and-results.mp4` (20-25s)
  - `02-stop-details.mp4` (20-25s)
  - `03-contribution.mp4` (25-30s)
